 画像（PNG）の共通ルール
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このフォルダの下の画像は、同じ名前の PNG で上書きするだけで差し替わります。

■ 形式
 ・PNG（.png）。背景は透明（調合机の背景など、全面を塗る絵は除く）
 ・JPG・PSD などは不可（拡張子が変わると別のファイル扱いになり、つながりが切れる）。PNG で書き出してください

■ 大きさ（ピクセル）
 ・各 README の「元の大きさ」は目安です。大きく描いても小さく描いても構いません。
   上書きすると、ゲームの中での大きさが元と同じになるように自動で合わせます
   （元の大きさを .meta に覚えてあり、その比で計算します）。
   例：元が 90×90 のつまみを 180×180 で描く → ゲームの中では同じ大きさで、2倍細かく表示される
 ・縦横の比（形）は元と同じにしてください。比が違うと、横幅を基準に合わせるので縦がのび縮みします。
 ・おすすめは元の大きさの 1〜2 倍（最大 4096 ピクセル）。
 ・絵の真ん中が、置かれる位置の中心になります。キャンバスの真ん中に描いてください。

■ 「白で描く」絵
 一覧で【白で描く】とある絵は、ゲームの中で色が付きます（液体の色・素材の色・光の色など）。
 白〜灰色の濃淡と透明度だけで描いてください。色を付けて描くと、付ける色と混ざって濁ります。

■ 9スライス（ふちが伸びない絵）
 一覧で【9スライス：ふち N】とある絵は、ウィンドウの大きさに合わせて真ん中だけが伸びます。
 上下左右の端から N ピクセル（元の大きさのとき）は伸びないので、角の飾りはその内側に、伸びてもよい模様は真ん中に。
 大きく描いたときは、ふちの幅も同じ比で自動で太くなります。

■ 光について
 調合机の絵（Workbench・Liquid・Containers・Effects）は、ゲームの中のランプや火の光で照らされます。
 夜の暗さの中でも見えるように、少し明るめに描くのがおすすめです。UI（画面の部品）は光の影響を受けません。

■ 上書きしたあと
 Unity に切り替えると自動で読み込みます（数秒）。▶ で確かめて、PNG と .meta をコミット。
