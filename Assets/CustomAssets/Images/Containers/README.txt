■ メモ
 ・container_ の絵は、素材に自分の絵（Ingredients の <素材ID>.png）がないときの代わりです。
   今はすべての素材に絵があるので、ふだんは使われません（新しい素材を足したときの予備）
 ・potion_bottle の2枚は、いつも使われます（作った液体の色で中身が塗られる）
