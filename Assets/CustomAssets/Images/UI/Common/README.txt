■ メモ
 ・羊皮紙（parchment.png・Discovery の page.png）は、ゲームの中で少しくすんだ暖色を掛けて表示します（暗い夜の画面で、紙が白く浮かないように）。
   掛ける色は UISkin（Assets/Art2D/UI/UISkin.asset）の「Paper Tint」。白にすると絵そのままの色になります
 ・9スライスの絵は、元の大きさが小さくても大丈夫。きれいに見せたいなら 2〜4 倍で描くと、ふちも自動で同じ比になります
