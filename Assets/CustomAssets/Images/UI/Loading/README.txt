 ロード画面の絵
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

タイトルで「はじめから」「つづきから」を選ぶと、この1枚絵が画面いっぱいに出て、右下に小さく「Loading...」と表示されます（2〜3秒）。光の影響は受けません。

■ ファイルの一覧
 ・loading_background.png（元の大きさ 1920×1080）
     画面いっぱいの1枚絵。全面を塗る（透明にしない）。好きなイラストに差し替えられる。今は深い夜の色の仮の絵

■ 差し替え方
 ・自分の絵を「loading_background.png」という名前の PNG にして、このフォルダのファイルに上書きするだけ
   （Unity で設定を触る必要はありません。.meta は消さない・動かさない）

■ 描くときのコツ
 ・縦横の比は 16:9（1920×1080。3840×2160 でも可）
 ・右下（端から 横 240×縦 90 ピクセルほど）に「Loading...」の小さなクリーム色の字が出ます。そこは暗め・静かな絵柄にすると読みやすい
 ・字が読みにくいときは、UISkin（Assets/Art2D/UI/UISkin.asset）の「Loading Shade」を 0.2〜0.4 に上げると、絵全体が少し暗くなる（今は 0＝絵そのまま）

■ 長さ（秒）を変えたいとき
 ・シーンの AtelierHUD を選ぶ → インスペクターの「タイトル → 調合机の切り替え」
   絵が出るまで 0.6・見せておく 1.1・消えるまで 0.8（合計 2.5 秒）を数字で変えられます

■ ルール（画像の共通ルールは Images/README.txt）
 ・PNG・背景は透明・ファイル名はそのまま（拡張子も .png のまま）で上書き
 ・大きさは目安。大きく描いても、ゲームの中の大きさは自動でそろう（縦横の比は元と同じに）
 ・上書きしたら、同じ名前の .meta も一緒にコミット（.meta は消さない・動かさない）
