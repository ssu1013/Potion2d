 日付のアイキャッチの絵
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

タイトルで「はじめから」「つづきから」を選ぶと、画面が暗くなって日付（4月12日 など）が浮かびます。その画面の絵です。光の影響は受けません。

■ ファイルの一覧
 ・date_background.png（元の大きさ 1920×1080）
     画面いっぱいの背景。全面を塗る（透明にしない）。夜空・机の手元・暦のイラストなどに差し替えられる。今は深い夜の色の仮の絵
 ・date_ornament.png（元の大きさ 512×32）
     日付の下の飾りの線（背景は透明）。日付と「〇日目の夜」の間に出る

■ 重なりの順（奥 → 手前）
 1. date_background.png（背景）
 2. 暗がり（ゲームが重ねる黒。文字を読みやすくするため。濃さは UISkin の「Date Shade」0〜0.9、今は 0.25）
 3. 日付の文字（画面の真ん中より少し上。大きなクリーム色の字）
 4. date_ornament.png（真ん中より少し下）
 5. 「〇日目の夜」「これまでに瓶に詰めた回数」の小さな字

■ 描くときのコツ
 ・文字は画面の真ん中あたり（横 1400×縦 320 ピクセルほど）に出ます。そこは暗め・静かな絵柄にすると読みやすい
 ・明るいイラストにするなら、UISkin（Assets/Art2D/UI/UISkin.asset）の「Date Shade」を 0.4〜0.6 に上げる
 ・縦横の比は 16:9 のまま（大きさは 3840×2160 でも可）

■ 演出の「間」（秒）を変えたいとき
 ・シーンの AtelierHUD を選ぶ → インスペクターの「日付のアイキャッチの『間』」
   暗くなるまで・日付が浮かぶまで・見せておく時間・消えるまで・机が見えてくるまで、を数字で変えられます
 ・1日目の月日は Assets/GameData/GameBalance.asset の「暦」（今は 4月1日）
 ・浮かび上がるときの音は Sounds/SE/UI/se_date.wav

■ ルール（画像の共通ルールは Images/README.txt）
 ・PNG・背景は透明・ファイル名はそのまま（拡張子も .png のまま）で上書き
 ・大きさは目安。大きく描いても、ゲームの中の大きさは自動でそろう（縦横の比は元と同じに）
 ・上書きしたら、同じ名前の .meta も一緒にコミット（.meta は消さない・動かさない）
