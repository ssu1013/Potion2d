 タイトル画面の絵
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

タイトル画面の後ろに、画面いっぱいに出す1枚絵です（調合机・フラスコ・素材トレイはこの絵で隠れます）。光の影響は受けません。

■ ファイルの一覧
 ・title_background.png（元の大きさ 1920×1080）
     画面いっぱいの1枚絵。全面を塗る（透明にしない。透けた所は暗い色になる）。好きなイラストに差し替えられる。今は月夜の丘と、灯りのともる小さな工房の仮の絵

■ 差し替え方
 ・自分の絵を「title_background.png」という名前の PNG にして、このフォルダのファイルに上書きするだけ
   （Unity で設定を触る必要はありません。.meta は消さない・動かさない）

■ 描くときのコツ
 ・縦横の比は 16:9（1920×1080。3840×2160 でも可）
 ・上の真ん中（上から 100〜480 ピクセルほど）にロゴ「ポーション・フロンティア」とサブタイトル、
   真ん中から下（上から 580〜1000 ピクセルほど）にボタンと「つづきから」の情報が重なります。そこは静かな絵柄にすると読みやすい
 ・ロゴの左右（上から 300 ピクセルほど、端から 130 ピクセルほど）に、ポーションの瓶のかざりが出ます
 ・ふちの暗がり（UI/Common の vignette.png）と光の粒は、ゲームが絵の上に重ねます
 ・ロゴやボタンが読みにくいときは、UISkin（Assets/Art2D/UI/UISkin.asset）の「Title Shade」を 0.2〜0.4 に上げると、絵全体が少し暗くなる（今は 0＝絵そのまま）

■ 遊びはじめるとき
 ・「はじめから」「つづきから」を押すと、ロゴとボタンがすっと消え、この絵が Loading/ のロード画面の絵へ静かに入れ替わってから、調合机が現れます
 ・ロード画面をはさまずに、この絵から直接、調合机へフェードさせたいときは、シーンの AtelierHUD の
   「タイトル → 調合机の切り替え」で「Show Loading Screen」をオフにする（消えていく長さは「Title Fade Out Seconds」）

■ ルール（画像の共通ルールは Images/README.txt）
 ・PNG・背景は透明・ファイル名はそのまま（拡張子も .png のまま）で上書き
 ・大きさは目安。大きく描いても、ゲームの中の大きさは自動でそろう（縦横の比は元と同じに）
 ・上書きしたら、同じ名前の .meta も一緒にコミット（.meta は消さない・動かさない）
