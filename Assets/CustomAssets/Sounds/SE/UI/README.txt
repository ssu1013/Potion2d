 画面の音
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ボタン・ウィンドウ・ページなど、画面を操作したときの音です。

■ ファイルの一覧（かっこの中は今の長さ）
 ・se_ui_click.wav（0.1秒）
     ボタンを押したとき
 ・se_ui_hover.wav（0.05秒）
     ボタンにカーソルを乗せたとき（とても短く小さく）
 ・se_ui_open.wav（0.6秒）
     ウィンドウ・本を開いたとき
 ・se_ui_close.wav（0.5秒）
     ウィンドウ・本を閉じたとき
 ・se_page.wav（0.6秒）
     ページをめくる音（レシピ本・素材ノート・新発見のページめくり）
 ・se_start_game.wav（1.7秒）
     タイトルで「はじめから」「つづきから」を選んだとき
 ・se_warning.wav（0.7秒）
     できないことをしたとき

■ ルール（音の共通ルールは Sounds/README.txt）
 ・WAV（44100Hz・16bit 推奨）・ファイル名はそのまま（拡張子も .wav のまま）で上書き
 ・「ループ」とある音は、終わりと始まりが自然につながるように（頭と終わりに無音を入れない）
 ・上書きしたら、同じ名前の .meta も一緒にコミット（.meta は消さない・動かさない）
