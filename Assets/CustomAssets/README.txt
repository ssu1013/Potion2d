 差し替え用の素材フォルダ（ポーション・フロンティア 2D）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ここにある画像・音・フォントを「同じ名前・同じ形式のファイルで上書き」するだけで、
ゲームの中の絵や音が切り替わります。Unity で Prefab やスクリプト・設定を触る必要はありません。
（ゲームは1画面：夜の調合机だけ。部屋・お店の絵と音は _Unused に予備として残してあります）

■ フォルダの地図
CustomAssets/
├─ Images/                画像（PNG）
│   ├─ Ingredients/       素材のアイコンと、フラスコに落ちる欠片（素材ID の名前）
│   ├─ Workbench/         調合机（背景・ランプ・フラスコ・加熱台・炎・つまみ・ガラス棒・右の素材トレイ）
│   ├─ Liquid/            液体（中身・液面・注ぐ流れ・欠片）
│   ├─ Containers/        入れ物（素材の瓶・壺・袋など／瓶詰めした液体の瓶）
│   ├─ Effects/           湯気・泡・しぶき・渦・波紋
│   ├─ UI/
│   │   ├─ Common/        羊皮紙・木の板・ボタン・マスなど、画面の部品
│   │   ├─ Brew/          調合机の温度計・溶け具合の輪
│   │   ├─ Discovery/     素材ノート・新発見のページ・スタンプ・素材が届いた手紙
│   │   ├─ Loading/       ロード画面（タイトルから遊びはじめるときに出る1枚絵）
│   │   └─ Title/         タイトル画面の後ろに出す1枚絵（後ろの調合机を隠す）
│   └─ _Unused/           今のゲームでは使わない絵（予備。部屋・お店の絵など）
├─ Sounds/                音（WAV）
│   ├─ BGM/               曲
│   ├─ Ambient/           ずっと流れる環境音（夜の空気・ランプの火）
│   ├─ SE/
│   │   ├─ UI/            ボタン・ページ・ウィンドウの音
│   │   ├─ Brewing/       注ぐ・混ぜる・煮える・火・瓶詰め・お湯のコトコト・ガラス
│   │   └─ Feedback/      ★・新発見・反応・素材が届いた・注意（手ごたえの音）
│   └─ _Unused/           今のゲームでは鳴らない音（予備。お店・相談・足音の音など）
└─ Fonts/                 文字のフォント

それぞれのフォルダの README.txt に「ファイル名・元の大きさ・どこで使われるか・注意点」の一覧があります。

■ 差し替えの手順
 1. 替えたいファイルの名前を、そのフォルダの README.txt で確かめる
 2. 自分の画像・音を「まったく同じ名前・同じ拡張子」にして、エクスプローラーで上書きする
 3. Unity に切り替えると自動で読み込まれる。▶（再生）で確かめる
 4. GitHub に上げるときは、上書きしたファイルと、同じ名前の .meta の両方をコミットする
    （画像は、大きさが元と違うと .meta が自動で書き換わります。それも一緒にコミット）

■ やってはいけないこと（ゲームとのつながりが切れます）
 ・.meta ファイルを消す・動かす・名前を変える（ファイルとゲームをつなぐ「名札」です）
 ・ファイルの名前や拡張子を変える（.png → .jpg、.wav → .mp3 など）
 ・フォルダを動かす・名前を変える
 ※ いったん消してから同じ名前で置き直すと、.meta も消えて別のファイル扱いになることがあります。
   必ず「上書き」で置いてください。

■ 新しいファイルを足したいとき
 ここに新しい名前のファイルを置いても、ゲームはまだ使いません（どこで使うかの指定が必要）。
 新しい素材・新しい音の場面を足すときは、相談してください。

■ うまくいかないとき
 ・Unity のメニュー「Tools > Potion Frontier 2D > Step7：差し替え用ファイルのつながりを確認」
   → つながりの切れた欄・どこからも使われていないファイル（名前のつづり違いなど）の一覧が出ます
 ・「Tools > Potion Frontier 2D > 仕上げ > ④ 通しテスト」でも、絵と音のつながりを確かめます
 ・元に戻したいときは、VS Code の「ソース管理」で、そのファイルの変更を取り消す（↶）

■ ほかのフォルダ（触らなくて大丈夫）
 ・Assets/Art2D … Prefab と、絵の設定（UISkin・BrewArt2D）。絵そのものはここ（CustomAssets）にあります
 ・Assets/Audio … 音の設定（SoundLibrary）だけ
 ・Assets/GameData … 素材・反応のデータ（素材が机に届く時期＝「届くのに必要な発見」もここ）
