ここには、絵の「置き方」の設定だけがあります。絵そのものは Assets/CustomAssets/Images です。

 ・Brewing/Prefabs … 調合台・部屋の部品（Prefab）。絵は CustomAssets の画像を参照しています
 ・Brewing/BrewArt2D.asset … 調合台の絵の一覧（入れ物・湯気など）
 ・UI/UISkin.asset … 画面の部品の絵・フォントの一覧

絵を替えるときは、ここではなく Assets/CustomAssets の画像を同じ名前で上書きしてください。
